# Configuration

## 3CX Phone System URL

Enter the HTTPS origin of the 3CX system, for example:

`https://1266.3cx.cloud`

Use the actual hostname assigned to the installation. Do not include credentials, query strings or fragments.

## 3CX Party ID

Enter the Party ID copied from the 3CX Live Chat configuration, for example:

`LiveChat674776`

## Publication

Publish the Joomla site module in the intended template position and assign it to the required menu items. Verify that the chat interface appears on the public site and that the browser loads the official 3CX widget script.
