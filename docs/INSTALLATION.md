# Installation

1. Download the latest published ZIP from GitHub Releases.
2. In Joomla 6, open **System → Install → Extensions**.
3. Upload the ZIP package.
4. Create a site module named **3CX by Frydendal**.
5. Enter the HTTPS Phone System URL and the 3CX Live Chat Party ID.
6. Publish the module, select a module position and configure menu assignment.
7. Check the front end and browser console on every intended menu assignment.

Do not install a source-code archive from the repository's Code menu. Use the versioned ZIP asset attached to a GitHub Release.
